# Imbalance Experiment Results and Analysis

## 1. Experiment Goal

The first round of five baseline models showed a consistent pattern: Accuracy and Log Loss looked acceptable, but Macro F1 stayed around `0.1655`, and minority classes `label=1~5` were almost never predicted.

This follow-up experiment therefore focused on class imbalance. Three strategies were evaluated:

- Experiment 1: TabPFN with prior probability correction;
- Experiment 2: TabPFN with synthetic Class 1 augmentation;
- Experiment 3: a two-stage LightGBM + TabPFN pipeline.

All results below come from the GPU run using the same enhanced preprocessing pipeline and the same validation split.

## 2. Final Results

| Best prior correction: `prior_grid_class1_0.05` | 0.392657 | 0.166754 | 0.955295 | 0.000000 | 0.117647 |
| Best synthetic augmentation: `synthetic_class1_50` | 0.085691 | 0.165528 | 0.986429 | 0.000000 | 0.000000 |

If the main selection metric is `Macro F1`, the best current model is:

```text
Model: LightGBM Stage 1 + TabPFN Stage 2
Configuration: two_stage_w50_t0.05
Macro F1: 0.232194
```

Compared with the original TabPFN baseline:

```text
Macro F1: 0.165528 -> 0.232194
Absolute improvement: +0.066666
Relative improvement: about +40.3%
```

However, this improvement should be interpreted carefully. Overall minority Recall is still only `0.019608`, meaning that only about `1/51` minority validation samples was correctly captured. Class 1 Recall is still `0`.

## 3. Experiment 1: TabPFN Prior Correction

The best prior-correction setting was:

```text
prior_grid_class1_0.05
Log Loss: 0.392657
Macro F1: 0.166754
Accuracy: 0.955295
Class 1 Recall: 0.000000
Minority Recall: 0.117647
```

This experiment did push the model to predict minority classes more often. Overall minority Recall increased from `0` to `0.117647`. However, Macro F1 barely improved, while Accuracy and Log Loss became much worse.

The conclusion is that prior correction can expose some minority-class signal in TabPFN probabilities, but it also hurts calibration and introduces many false positives. It is useful as an analysis experiment, but it is not a strong final model in the current form.

## 4. Experiment 2: Synthetic Class 1 Augmentation

The best synthetic augmentation setting was:

```text
synthetic_class1_50
Log Loss: 0.085691
Macro F1: 0.165528
Accuracy: 0.986429
Class 1 Recall: 0.000000
Minority Recall: 0.000000
```

This version did not produce visible improvement. Its Macro F1, Accuracy, and minority Recall were essentially identical to the original TabPFN baseline.

This does not necessarily prove that EPIC-style LLM augmentation is ineffective. The current implementation used reproducible statistical perturbation rather than medically informed LLM-generated records. With only five real Class 1 examples and only one Class 1 sample in validation, this simple augmentation was not enough to change the decision boundary.

## 5. Experiment 3: Two-stage LightGBM + TabPFN

The best two-stage model was:

```text
two_stage_w50_t0.05
Stage 1: LightGBM binary detector, class_weight={0:1, 1:50}
Stage 1 threshold: 0.05
Stage 2: TabPFN minority-class refinement
Log Loss: 0.194258
Macro F1: 0.232194
Accuracy: 0.986429
Class 1 Recall: 0.000000
Minority Recall: 0.019608
```

This is the best model by Macro F1. It improved Macro F1 from `0.165528` to `0.232194` without reducing Accuracy.

The main advantage is structural: the model separates abnormality detection from minority-class refinement. This is more appropriate for the current dataset than forcing one multiclass model to learn all rare labels directly.

The limitation is also clear. Log Loss is worse than raw TabPFN, and minority Recall is still low. The model made progress, but it did not fully solve rare-class recognition.

## 6. Current Final Model Choice

Based on the current experiments, the best final model is:

```text
Final model: LightGBM Stage 1 + TabPFN Stage 2
Best configuration: two_stage_w50_t0.05
Macro F1: 0.232194
Accuracy: 0.986429
Log Loss: 0.194258
```

The reason for choosing this model is that it achieved the highest Macro F1 among the imbalance-focused experiments. It also kept Accuracy unchanged relative to the TabPFN baseline.

At the same time, this choice should be reported with caution:

- If the goal is probability quality, raw TabPFN and AutoGluon have better Log Loss;
- If the goal is Macro F1 and minority-class recognition, the two-stage model is currently better;
- Class 1 is still not successfully recovered, so the rarest class remains the main unresolved issue.

## 7. Suggested Report Wording

After observing that all five baseline models degenerated into majority-class predictors, three imbalance-oriented strategies were tested. Prior correction increased overall minority Recall but substantially worsened Log Loss and Accuracy, indicating that directly changing the class prior creates many false positives. The synthetic Class 1 augmentation experiment did not improve Macro F1 under the current statistical-perturbation implementation. The two-stage LightGBM + TabPFN model achieved the best Macro F1, improving from `0.1655` to `0.2322` while maintaining Accuracy at `0.9864`. Therefore, the two-stage model is selected as the current best model. However, minority Recall remains low and Class 1 Recall is still 0, showing that extreme rare-class recognition remains the core challenge of this task.

## 8. Next Steps

Recommended next experiments:

- Run a denser Stage 1 threshold scan between `0.01` and `0.10`;
- Optimize Stage 1 for fixed minority Recall before minimizing false positives;
- Try cross-validation because the validation set has only one Class 1 sample;
- Replace simple synthetic perturbation with LLM-generated EPIC-style synthetic records;
- Consider a binary `label=0` vs `label>0` objective as a separate reporting target.
